# 🚗 VietCar-ISA: A Benchmark for Vietnamese Implicit Sentiment Understanding in the Automotive Domain

---
> **VietCar-ISA: A Vietnamese Implicit Sentiment Dataset and Evaluation of Large Language Models in the Automotive Domain**
>
> Quoc-Thai Nguyen¹, Quyet-Thang Huynh¹*
>
> ¹School of Information and Communication Technology, Hanoi University of Science and Technology, Hanoi, Vietnam
---

Official repository for **VietCar-ISA**, a Vietnamese implicit sentiment analysis benchmark for automotive discussions.

VietCar-ISA evaluates whether Large Language Models (LLMs) can understand Vietnamese implicit sentiment. The dataset contains **302 human-validated Vietnamese automotive comments** with rich annotations including sentiment polarity, implicit type, and a supporting rationale.

The project makes three main contributions:

- We introduce **VietCar-ISA**, to our knowledge the first Vietnamese implicit sentiment benchmark for the automotive domain.
- We evaluate four representative LLMs using a few-shot chain-of-thought prompting setup.
- We assess both **sentiment classification** and **explanation quality**, providing a more comprehensive view of Vietnamese implicit sentiment understanding in LLMs.

---

## 📊 Dataset

### Dataset Structure

Each instance contains the following fields:

| Field | Description |
|---|---|
| `comment` | The original Vietnamese automotive comment collected from online discussion forums. |
| `sentiment` | The sentiment polarity of the comment: `Positive` or `Negative`. |
| `implicit_type` | The implicit sentiment category: `Fact-implied`, `Ironic`, `Metaphorical`, or `Rhetorical-question`. |
| `rationale` | A concise explanation of the implicit meaning and how it conveys the corresponding sentiment. |

### Sentiment Distribution

| Sentiment | Count | Percentage |
|---|---:|---:|
| Negative | 235 | 77.81% |
| Positive | 67 | 22.19% |
| **Total** | **302** | **100%** |

### Implicit Sentiment Types

| Type | Count | Percentage |
|---|---:|---:|
| Fact-implied | 128 | 42.38% |
| Ironic | 79 | 26.16% |
| Metaphorical | 49 | 16.23% |
| Rhetorical-question | 46 | 15.23% |

## 🧪 Method

We evaluate four representative LLMs using the same **few-shot Chain-of-Thought prompting** configuration with six demonstration examples:

- **DeepSeek-V4**
- **GPT-5.5**
- **Gemini-3.6-Flash**
- **Gemma-4-31B**
  
### Classification Evaluation

Sentiment classification is evaluated using Accuracy, Macro-F1, Positive-F1, Negative-F1. Macro-F1 is used as the primary metric due to the class imbalance in the VietCar-ISA dataset.

### Explanation Evaluation

We additionally evaluate the explanations generated by each model through human evaluation.

Each explanation is rated as:

- **Agree** — correctly identifies and explains the intended implicit meaning
- **Neutral** — captures the main meaning but is incomplete or partially inaccurate
- **Disagree** — substantially misinterprets or fails to identify the intended implicit meaning

## 🎯 Key Findings

- LLMs perform best on **fact-implied sentiment**, while **Ironic expressions** are usually the most challenging category.
- DeepSeek-V4 may predict the correct sentiment while providing explanations that are inconsistent with human interpretations.
- Common failure patterns include:
  - missing subtle pragmatic cues;
  - failing to identify the primary sentiment target;
  - failing to recognize non-standard or community-specific vehicle names.

These results highlight the importance of evaluating both **classification performance** and **model-generated explanations** when studying implicit sentiment understanding.

## ⚙️ Setup

Clone the repository:

```bash
git clone https://github.com/thainguyenquoc0828/VietCar-ISA.git
cd VietCar-ISA
```

Install the required dependencies:
```bash
python -m pip install -r requirements.txt
```
Set your OpenRouter API key:

```bash
export OPENROUTER_API_KEY="your_openrouter_api_key_here"
```

On Windows PowerShell:

```powershell
$env:OPENROUTER_API_KEY="your_openrouter_api_key_here"
```

Run inference with one of the supported models:
```bash
# Gemma-4-31B
python inference.py \
  --model google/gemma-4-31b-it \
  --input_path data/VietCar-ISA.csv \
  --output_dir outputs

# GPT-5.5
python inference.py \
  --model openai/gpt-5.5 \
  --input_path data/VietCar-ISA.csv \
  --output_dir outputs

# Gemini-3.6-Flash
python inference.py \
  --model google/gemini-3.6-flash \
  --input_path data/VietCar-ISA.csv \
  --output_dir outputs

# DeepSeek-V4
python inference.py \
  --model ~deepseek/deepseek-v4-flash-latest \
  --input_path data/VietCar-ISA.csv \
  --output_dir outputs
```

To reproduce the experiments:

1. Clone the repository.
2. Place the dataset at `data/VietCar-ISA.csv`.
3. Set the `OPENROUTER_API_KEY` environment variable.
4. Run inference using the model commands above.
5. Collect generated outputs under `outputs/`.
